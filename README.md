
# QA Testing Portfolio – E-commerce Web Application

## Project Overview

This project demonstrates my hands-on QA skills using a demo e-commerce web application. It showcases manual functional testing, accessibility testing, API testing, and SQL validation.
The goal is to highlight my ability to write test cases, execute tests, report bugs, and validate data in both the UI and the backend.


## Scope of Testing

* Manual Functional Testing: UI elements, input validations, and business logic verification
* Accessibility Testing: WCAG basics, keyboard navigation, screen reader checks
* Cross-Browser Testing: Chrome and Safari
* API Testing: Postman collections for endpoints and validation
* Database Validation: SQL queries for backend verification
* Bug Reporting & Test Documentation: Jira for defect tracking, screenshots for evidence

* TestRail – Test case management
* Jira – Defect reporting and tracking
* Postman – API testing
* MySQL / DBeaver – Database validation
* Chrome DevTools – Cookies, sessions, and UI inspection
* GitHub – Project documentation and portfolio
