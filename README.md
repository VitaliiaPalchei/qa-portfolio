# QA Testing Portfolio – E-commerce Web Application

## Project Overview
This project demonstrates my hands-on QA skills using a demo e-commerce web application.
It includes manual functional testing, accessibility checks, API testing, and SQL validation.

## Scope of Testing
- Manual functional testing (UI, validation, business logic)
- Accessibility testing (WCAG basics, keyboard navigation)
- Cross-browser testing (Chrome, Safari)
- API testing using Postman
- Database validation using SQL
- Bug reporting and test documentation

## Project Structure
- Test Plan
- Acceptance Criteria
- Manual Test Cases + Bug Reports
- API Test Cases + Postman evidence
- SQL Test Cases + DB validation evidence
- TestRail screenshots

## Tools Used
- TestRail – test case management
- Jira – defect reporting
- Postman – API testing
- MySQL – database validation
- Chrome DevTools – cookies/session testing
- GitHub – documentation and portfolio

Demo Web Shop (Tricentis)
