
 ## Title: Add to Cart Button Not Accessible via Keyboard on Product Details Page
 
**Environment:**
OS: macOS
Browsers:
Chrome (latest)
Safari (latest)

**Preconditions:**
User relies on keyboard navigation (no mouse).

**Steps to Reproduce:**
1. Open the website homepage.
2. Navigate to a product category (e.g., Apparel & Shoes) using the keyboard only.
3. Select a product and open its Product Details Page (PDP) using the keyboard.
4. Press Tab to navigate to the Add to Cart button.

**Actual Result:**
The focus skips the “Add to Cart” button.
Keyboard users cannot activate the button without using a mouse.

**Expected Result:**
All interactive elements, including the “Add to Cart” button, are reachable and operable via keyboard navigation.
Users can add a product to the cart without using a mouse.

**Severity:**  High
**Priority:**  High
