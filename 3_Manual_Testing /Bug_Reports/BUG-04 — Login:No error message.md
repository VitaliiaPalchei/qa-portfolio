
## Title: No error message shown for incorrect login credentials

**Environment:**
Chrome, macOS

**Preconditions:**
User has an existing account.

**Steps to Reproduce:**
1. Open the Login page.
2. Enter a valid registered email.
3. Enter an incorrect password.
4. Click Login.
   
**Actual Result:**
Login fails, but no error message is displayed.

**Expected Result:**
The user should see a clear error message indicating that the credentials are invalid.

**Severity:** Medium

**Priority:** Medium
