
## Title: First Name field accepts numeric characters during registration

**Environment:**

OS: macOS

Browser: Chrome (latest)

URL: Demo Web Shop

Page: Registration

**Steps to Reproduce:**
1. Open the website homepage.
2. Navigate to the Register page.
3. Enter 4 in the First Name field.
4. Complete other required fields with valid data.
5. Submit the registration form.
   
**Actual Result:**
Registration has been successfully completed.
Numeric values are accepted in name fields.

**Expected Result:**
First Name and Last Name fields should reject numeric characters.
Validation error message should be displayed.

**Severity:**  Medium

**Priority:**  Medium
