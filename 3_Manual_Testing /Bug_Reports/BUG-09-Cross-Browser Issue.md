
## Title: Password visibility(eye) icon is missing on login page in Safari browser

**Priority:** Medium

**Severity:** Medium

**Environment:**
OS: macOS
Browser:
Safari (latest)
Chrome (latest) 

**Steps to Reproduce:**
1. Open the website in Safari.
2. Navigate to the Login page.
3. Click on the Password field.
   
**Expected Result:**
A password visibility (eye) icon is displayed next to the password field.
The user can toggle password visibility by clicking the icon (as in Chrome).

**Actual Result:**
The password visibility (eye) icon is not displayed in Safari.
The user cannot toggle password visibility.

**Notes / Additional Information:**
The password visibility icon is present and works correctly in Google Chrome.
