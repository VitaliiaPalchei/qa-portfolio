
## Title: Product image does not update when selecting a different color on PDP

**Environment:**
OS: macOS
Browser: Chrome (latest)
URL: Demo Web Shop

**Steps to Reproduce:** 
1. Open the website homepage.
2. Navigate to the Apparel & Shoes category.
3. Open the Blue and Green Sneakers product page.
4. Select the Black color option.

**Expected Result:**
The product image should update correctly based on the selected color.

**Actual Result:**
PDP displays the same (green) shoe image.

**Severity:**  High

**Priority:**  High
