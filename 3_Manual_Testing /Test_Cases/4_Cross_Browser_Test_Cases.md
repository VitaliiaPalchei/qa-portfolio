## TC-CB-01: Verify Website Loads Correctly in Supported Browsers

**Browsers:**  Chrome, Safari

**Steps:**
1. Open the website homepage in Chrome.
2. Observe the page layout and main elements.
3. Open the same website homepage in Safari.
4. Observe the page layout and main elements.
   
**Expected Result:**
- Homepage loads successfully in both browsers.
- Header, footer, navigation menu, and main content are displayed correctly.
- No layout breaks, missing elements, or visual distortions.

## TC-CB-02: Verify Category Page and PLP Display in Chrome and Safari

**Browsers:**  Chrome, Safari

**Steps:**
1. Open the website in Chrome.
2. Open any product category.
3. Verify the Product Listing Page (PLP).
4. Repeat the same steps in Safari.
   
**Expected Result:**
- Category page opens successfully in both browsers.
- Product list is displayed correctly.
- Product tiles, images, prices, and buttons render consistently.
- No overlapping text or broken layouts.

## TC-CB-03: Verify Product Details Page (PDP) in Chrome and Safari

**Browsers:**  Chrome, Safari

**Steps:**
1. Open the website in Chrome.
2. Navigate to a product details page.
3. Verify product image, name, price, and action buttons.
4. Repeat the same steps in Safari.
   
**Expected Result:**
- PDP loads correctly in both browsers.
- All product information is visible and readable.
- Buttons (Add to Cart, Add to Wishlist, Email a Friend) are displayed correctly.

## TC-CB-04: Verify Add to Cart Functionality in Chrome and Safari

**Browsers:**  Chrome, Safari

**Steps:**
1. Open the website in Chrome.
2. Open any in-stock product.
3. Click the Add to Cart button.
4. Verify the cart update.
5. Repeat the same steps in Safari.
   
**Expected Result:**
- Product is successfully added to the cart in both browsers.
- Confirmation message appears.
- Cart icon item count updates correctly.

## TC-CB-05: Verify Cart Page Functionality in Chrome and Safari

**Browsers:**  Chrome, Safari

**Steps:**
1. Open the Cart page in Chrome with at least one product added.
2. Verify product details, quantity, and total price.
3. Change product quantity.
4. Remove a product using the Remove selected items button.
5. Repeat the same steps in Safari.
   
**Expected Result:**
- Cart page functions correctly in both browsers.
- Quantity updates recalculate totals correctly.
- Products are removed successfully when selected and removed.
- No functional or UI issues observed.

## TC-CB-06: Verify Checkout Navigation in Chrome and Safari

**Browsers:**  Chrome, Safari

**Steps:**
1. Open the Cart page in Chrome.
2. Select the “I agree with the terms of service” checkbox.
3. Click Proceed to Checkout.
4. Repeat the same steps in Safari.
   
**Expected Result:**
- User can proceed to checkout in both browsers.
- Checkout page loads without errors.
- Navigation behavior is consistent across browsers.
